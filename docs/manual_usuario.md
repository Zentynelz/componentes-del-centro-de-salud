# Manual de usuario - Aplicación Centro de Salud

## Objetivo

La aplicación permite consultar los 4 reportes mínimos solicitados por el centro de salud:

1. Pacientes a cargo de un médico según especialidad.
2. Médicos disponibles para una especialidad.
3. Pacientes diagnosticados con determinada enfermedad.
4. Médicos con vacaciones disfrutadas o planeadas en un intervalo de fechas.

## Ejecución

Desde la raíz del proyecto:

```bash
streamlit run app/main.py
```

## Uso general

1. Abrir la aplicación en el navegador.
2. Verificar que aparezca el mensaje de conexión exitosa.
3. Seleccionar un reporte desde el menú lateral.
4. Ingresar los filtros solicitados.
5. Presionar el botón de consulta.
6. Revisar la tabla de resultados.
